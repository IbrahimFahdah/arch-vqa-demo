dataset labels), not from a model.

The synthetic plans were never used in training (training used seeds 0-999). Their title blocks are cropped off.
The CubiCasa plans are from the dataset's test split, which was not trained on; other plans in the same drawing
style were.

## Questions to try

**synthetic_1**

| Question | Answer |
|---|---|
| What is the name of room 110? | BEDROOM |
| Which room has the largest labelled area? Answer with the room number. | 108 |
| What is the dimension between grid lines 3 and 4, in mm? | 7150 |
| Which rooms can be reached directly from room 102 through a single door? List the room numbers. | 101, 104 |
| Can you go directly from room 101 to room 106 through one door? | No |
| How many doors open into or out of room 108? Count every door in its walls. | 4 |

**synthetic_5**

| Question | Answer |
|---|---|
| Which room is in the north-west corner of the plan? North is up on the sheet. Answer with the room number. | 302 |
| What is the tag of the door between room 303 and room 304? | DR02 |
| Is there a door directly connecting room 304 and room 305? | Yes |
| Starting outside the building, what is the minimum number of doors you must pass through to reach room 304, counting the entrance door? | 2 |
| What is the overall east-west dimension of the plan, as dimensioned, in mm? | 11800 |

Add "Give only the final answer, without explanation." to a question for a short answer, as in training.
